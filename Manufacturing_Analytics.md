
It is used to analyze the manufacturing belt of a company. Where it has it's own database and tables related to it. It consists of analytics folder for each tables which provides the KPI's. 

Analytics folder consists of : 

    --init.py 
    --production.py 
    --factories.py 
    --machines.py 
    --quality.py 
    --employees.py 
    --trends.py

Dashboard folder consists of : 

    --init.py 
    --apps.py 
    --charts.py 
    --components.py 
    --dashboard_service.py

Includes charts like bar and donut charts fir factory production, machine status, factory production rate, factory defect rate and top performing employees.
